Script-based Video Generator for Astra Automation
Текущий этап проекта

Статус: Этап 1 — анализ, проектирование и формализация требований
Готовность: ~10–15% от общего объёма проекта

Данный репозиторий содержит результаты первого месяца разработки проекта по автоматизации генерации демонстрационных видеороликов для экосистемы Astra Automation.

На текущем этапе проект не является готовым генератором видео, а представляет собой архитектурную и методологическую основу, на базе которой будет реализован полноценный инструмент автоматической генерации видеоконтента.

Описание проекта
Проект направлен на автоматизацию создания демонстрационных видеороликов
на основе текстовых сценариев без ручной записи экрана и видеомонтажа.

Статус проекта
Реализован архитектурный MVP первого этапа:
разработан формат сценариев;
спроектирована модульная архитектура;
реализован минимальный прототип Screenshot Mode;
подтверждена возможность генерации MP4 из сценария.
Структура проекта

- scripts/ — примеры сценариев
- src/ — исходный код MVP
- input/ — входные изображения
- output/ — результат генерации
