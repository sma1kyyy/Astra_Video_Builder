# ОСНОВА YAML-СКРИПТА
Принципы написания скрипта, актуальные для любого режима записи.

*Обязательные поля помечены \* перед названием*

# * metadata
> Свойства видео-ролика, такие как название, описание, разрешение или количество кадров в секунду

---
- \* **title** - название видео-ролика
- \* **resolution** - разрешение видео-ролика. Значение задаётся в следующем формате: "ШиринаxВысота"
- **description** - описание видео-ролика для логирования
- **language** - язык восприятия текста и TTS. Доступны: 
    - ru *(default)*
    - en
- **mode** - режим записи видео-ролика. Доступны:
    - live *(default)*
    - screenshot
- **cursor** - отображать курсор или нет. Доступные значения:
    - true 
    - false *(default)*
- **fps** - количество кадров в секунду. Доступны:
    - 24
    - 30 *(default)*
    - 60

# acts
> Содержит в себе условные *акты*, из которых состоит видео-ролик. В каждом акте есть определенное количество сцен.

## act_object
> Объект акта, в котором расположены сцены. Название соответствует формату "act_id", где id - уникальный порядковый номер акта.

- **name** - название для акта. По умолчанию стоит id акта.

### * scenes
> Содержит в себе сцены, фрагменты, из которых состоит акт

---
#### scene_object
> Объект сцены, который содержит информацию о фрагменте видео-ролика, такие как длительность, действия, которые в нём происходят, изображения или музыка. Название соответствует формату: "scene_id", где id - уникальный порядковый номер сцены. Видео-ролик формируется из фрагментов по порядку, основанному на id.

---
- **duration** - минимальная длительность фрагмента в секундах (1 по умолчанию).
- **name** - название сцены для логирования
- **tts** - текст, который будет синтезироваться в речь
- **voice** - тип воспроизводимого голоса из tts. Доступные варианты:
    - jane *(default)*
    - zahar
- **subtitles** - включить или выключить субтитры, если работает tts. Доступные варианты:
    - true
    - false *(default)*
- **sub_place** - место для субтитров. Работает только при значении *true* у *subtitles*. Доступные варианты:
    - up
    - down *(default)*
    - center
- **effect** - определяет фильтр всего изображения. Доступные варианты:
    - *without* *(default)* - без особого фильтра
    - *black_white* - чёрно-белый фильтр
- **images** - содержит объекты *image_object*, которые будут размещены на фрагменте
- **audio** - содержит объекты *audio_object*, которые будут размещены на фрагменте
- **texts** - содержит объекты *text_object*, которые будут размещены на фрагменте

### image_object
> Определяет изображение, которое будет наложено на сцене. Название формируется по следующему шаблону: "image_id" - где id - уникальный порядковый номер изображения. Все изображения формируются по порядку, основанному на id.

---
- \* **path** - путь до изображения (файлы .png или .jpg)
- \* **start_x** - Задаёт изначальное положение изображения по x.
- \* **start_y** - Задаёт изначальное положение изображения по y.
- \* **resolution** - разрешение изображения, параметр, определяющий конечные точки расположения изображения. Значение задаётся в следующем формате: "ШиринаxВысота"
- **wait** - указывает длительность ожидания наложения изображения в секундах. Если задано, изображения появится только через переданный промежуток времени в рамках очереди, при этом задерживая оставшиеся изображения.
- **duration** - указывает длительность наложения изображения в секундах. Если задано, очередь к следующему изображению перейдет только тогда, когда текущее будет окончено.

### audio_object
> Определяет аудио (файл .mp3), которое будет на сцене. Название формируется по следующему шаблону: "audio_id" - где id - уникальный порядковый номер аудио. Все аудио формируются по порядку, основанному на id.

---
- \* **path** - путь до аудио (файлы .mp3)
- \* **_from** - откуда начать воспроизведение в секундах относительно аудио
- \* **duration** - сколько будет воспроизводится аудио в секундах, начиная с *from*.
- **wait** - сколько ждать перед началом воспроизведения в секундах (0 по умолчанию, то есть без задержки)

### text_object
> Определяет текст для сцены. Название формируется по следующему шаблону: "text_id" - где id - уникальный порядковый номер текста. Все текста формируются по порядку, основанному на id.

---
- \* **text** - задаёт содержание текста
- \* **start_x** - задаёт изначальное положение изображения по x.
- \* **start_y** - задаёт изначальное положение изображения по y.
- \* **size** - задаёт размер текста в пикселях
- **font** - задаёт шрифт текста из доступных. Доступные варианты:
    - *arial* *(default)*
    - *comic_sans*
- **wait** - указывает длительность ожидания наложения текста в секундах. Если задано, текст появится только через переданный промежуток времени в рамках очереди, при этом задерживая оставшиеся объекты.
- **duration** - указывает длительность наложения текста в секундах. Если задано, очередь к следующему тексту перейдет только тогда, когда текущий будет окончен.

# Особенности Live Recording
## scene_object
> Содержит дополнительное необязательное поле *actions*, в котором размещены *action_object*. Это действия, воспроизводимые в браузере в реальном времени

#### action_object
> Определяет действие, которое необходимо совершить в реальном времени. Название формируется по следующему шаблону: "action_id" - где id - уникальный порядковый номер действия. Все действия сцены формируются по порядку, основанному на id.

---
- \* **type** - тип выполняемого действия, основной параметр, от которого зависят другие параметры. Доступные типы:
    - *navigate* - перейти по какому-то URL
    - *click* - нажать на какую-то кнопку
    - *wait* - бездействовать в течение какого-то времени
    - *input* - ввести определенное значение в форму
    - *scrollUp* - поднять страницу вверх на определнное значение
    - *scrollDown* - опустить страницу вниз на определенное значение
    - *scrollTo* - перейти к какому-то элементу на странице
- **url** - обязателен для типа *navigate*. Указывает URL, куда необходимо перейти
  - **selector** - обязателен для типов: *click*, *input*, *scrollTo*. Указывает объект HTML, с которым будет проводиться действие. Шаблон (угловые скобки не писать): "//тег\[<параметр1> and <параметр2>...]". Параметров может быть сколько угодно, но как минимум должен быть один. Параметр строится по шаблону: "@аттрибут='значение'". Для поиска по тексту в тегах следующий формат: "text()='Текст'". Для поиска по началу значения: "starts-with(@attr, 'начало_значения_'". selector использует формат чистого xpath. 
- **text** - обязателен для типа *input*. Указывает текст, вводимый в форму.
- **duration** - обязателен для типа *wait*. Указывает количество *секунд* бездействия.
- **point** - обязателен для типов: *scrollUp*, *scrollDown*. Определяет количество единиц перемещения страницы.
- **behavior** - необязательный параметр для всех типов *scroll_*. Определяет поведение скролла, например `smooth` осуществляет плавный переход. Важно: работает только со статическими страницами, на страницы, которые подгружаются динамически через JS, behavior влиять не будет, вызывая ошибку, из-за чего скролл просто не сработает. Доступные значения:
    - *none (default)* - жёсткий переход ез поведения
    - *smooth* - плавный скролл
- **wait** - указывает длительность ожидания действия в секундах. Если задано, действие произойдёт только через переданный промежуток времени в рамках очереди, при этом задерживая оставшиеся изображения.


# Особенности Screenshot Mode
## scene_object
> Содержит дополнительные необязательные поля *annotations*, *transition* и *transpeed*. Так же определяет обязательное поле *path*.

- \* **path** - путь до файла .png или .jpg, который будет использоваться в качестве основного изображения.
- **transition** - определяет тип перехода на следующий фрагмент. Доступные варианты:
    - *without* *(default)* - просто склейка
    - *slideRight* - скольжение вправо
    - *slideLeft* - скольжение влево
    - *slideUp* - скольжение вверх
    - *slideDown* - скольжение вниз
    - *blackout* - затемнение
- **transpeed** - задаёт значение в секундах, сколько будет длиться переход. Работает только в том случае, если значение перехода не является *without*.
- **annotations** - содержит *annotation_object*, которые будут размещены на фрагменте

#### annotation_object
> Определяет аннотацию на скриншоте по координатам. Началом координат выступает левый верхний угол. Название формируется по следующему шаблону: "annotation_id" - где id - уникальный порядковый номер. Все аннотации формируются по порядку, основанному на id.

- \* **type** - тип аннотации. От него зависит, какие параметры будут необходимы (кроме оставшихся обязательных). Доступные варианты:
    - *square* - подсвечивает область квадратом
    - *line* - строит линию
    - *arrow* - строит стрелку в одну сторону
    - *darrow* - строит стрелку в обе стороны
- \* **transparency** - определяет прозрачность аннотации. Значение от 0 до 1, где 0 - это отсутствие прозрачности, а 1 - отсутствие аннотации.
- \* **start_x** - доступен для аннотации любого типа. Задаёт изначальное положение аннотации по x.
- \* **start_y** - доступен для аннотации любого типа. Задаёт изначальное положение аннотации по y.
- \* **end_x** - доступен для аннотации любого типа. Задаёт конечное положение аннотации по x.
- \* **end_y** - доступен для аннотации любого типа. Задаёт конечное положение аннотации по y.
- **wait** - указывает длительность ожидания наложения аннотации в секундах. Если задано, аннотация появится только через переданный промежуток времени в рамках очереди, при этом задерживая оставшиеся изображения.
- **duration** - доступен для аннотации любого типа. Задает время действия аннотации в секундах. Если указано, то следующая аннотация появится только тогда, когда текущая будет окончена. 
- **label** - доступен для аннотации любого типа. Задаёт небольшой текст рядом с аннотацией в зависимости от её типа. По умолчанию отсутствует.
- **text** - доступен только для типов: *square*. Задаёт текст *внутри* аннотации.
