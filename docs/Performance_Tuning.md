# Возможности оптимизации.

## цели
- сократить время рендера
- стабилизировать потребление ram
- минимизировать размер итогового mp4 без потери читаемости

## быстрые практики
1. снижайте fps до 24 для tutorial видео
2. используйте одинаковое разрешение всех входных изображений
3. не перегружайте сцену тяжелыми анимациями одновременно
4. ограничивайте длину tts для коротких сцен

## параметры moviepy/ffmpeg
в `screenshot_engine.py` сейчас используется:
- codec: `libx264`
- audio codec: `libmp3lame`
- threads: `4`

для слабой машины можно снизить нагрузку:
- уменьшить fps
- уменьшить разрешение
- уменьшить число одновременных оверлеев

## бенчмарк шаблон
```bash
time uv run python main.py -f examples/screenshot/screenshot_minimal.yaml -o output
```

рекомендуется вести таблицу:
- cpu
- ram
- длина итогового видео
- время рендера
