# Решение распространённых ошибок и проблем.
## 1. `Element not found.`
Ошибка, означающая, что элемент не был найден через `selector`. Скорее всего Вы допустили ошибку в написании, сверьтесь с руководством [режима Live Recording](Live_Recording_Mode_Guide.md).

## 2. `ModuleNotFoundError: yaml` или другие зависимости
```bash
uv sync
```

## 3. OCR ничего не находит
проверьте:
1. установлен ли tesseract (`tesseract --version`),
2. контраст текста на скриншоте,
3. язык `ocr_lang` (`rus+eng`),
4. порог `ocr_min_conf` (начните с 0.25-0.35).

## 4. smart annotation не попадает в элемент
- уточните `target_text` (точная фраза с интерфейса),
- уменьшите `ocr_min_conf`,
- увеличьте `auto_padding`,
- попробуйте `target_index: 1` если на экране несколько похожих надписей.

## 5. субтитры выглядят плохо на светлом фоне
используйте:
- `subtitle_style: contrast` или `cinematic`,
- `subtitle_bg_opacity: 0.55..0.75`.

## 6. tts не работает через api
если нет `YANDEX_API_KEY`, движок использует fallback wav, рендер не падает, но голоса не будет.

## 7. `ffmpeg` не найден
установите ffmpeg через пакетный менеджер вашей os и проверьте:
```bash
ffmpeg -version
```

## 8. ошибка с путями к скринам
проверьте что `scene.path` ведёт к реальному png/jpg и путь указан относительно корня запуска.

## 9. `pydantic_core._pydantic_core.ValidationError`
Скорее всего вы указали какой-то аттрибут, но ввели невалидное значение в него. Например, написали `123` в поле `type` у какого-нибудь `action`, что не подходит. Ознакомьтесь с текстом ошибки, в консоли будет выведено что именно можно вводить, и что именно ввели вы.
